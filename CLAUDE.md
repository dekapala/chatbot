# Easybot

Este archivo complementa (no reemplaza) las reglas globales de `~/.claude/CLAUDE.md`. Acá va SOLO lo específico de este proyecto.

## Qué es este proyecto
Frontend completo (sitio de marketing + plataforma) para Easybot, un SaaS de chatbots para PyMEs con modelo de autoservicio. Ver `vision.md` y `business.md` para el detalle.

## Stack
Next.js (App Router) + TypeScript + Tailwind CSS.
